# FloorLogic website

Marketing site for **FloorLogic**, Digital Horizon's flooring business software.
Live: https://floorlogic.vercel.app (Vercel project `floorlogic`, production = `main`).

## Run it

```bash
npm ci
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
npm test         # logic + parity tests (vitest)
```

## How it's built
- **Astro 7, static output.** Pages in `src/pages`, sections in `src/components/site`, the interactive product demos in `src/components/modules` + `src/islands`.
- **No backend, no database.** The site makes zero network calls of its own; `vercel.json` sets `connect-src 'self'`. The interactive demos run in the browser on fictional sample data (`src/data/sample-data.ts`).
- **Real product logic.** Quote math, cartons, roll goods, tax, deposits, "due now", the lead pipeline, work-order steps and job costing live in `src/lib/logic` and are tested against the app's own functions (`tests/parity`).
- **Free trial form.** Advertised, not wired yet. `src/lib/trial/submit-trial.ts` is the only thing to replace when a backend exists; today it saves and sends nothing, and the form says so.
- **Facts in one place.** Prices, trial terms, competitor census dates and proof figures: `src/config/site.ts`. Change a price there and every page, card and schema node follows.
- **Brand.** Logo SVGs and icons in `public/brand` + `public/`, regenerated by `tools/logo`. Fonts self-hosted in `public/fonts` (Supreme, Satoshi; Inter only inside product screens).
- **Motion.** GSAP (home page only), always behind `prefers-reduced-motion`.
- **Easter egg.** Every roll has a dye lot.

## Before launch
- Wire the trial backend (`submit-trial.ts`) before running ads.
- Owner review of `/privacy` and `/terms`.
- Re-check competitor facts by the date in `CENSUS.nextDue`.
- Domain: switch `SITE_URL` in `astro.config.mjs` and `SITE.url` in `src/config/site.ts` together.
